Tracking the WebExtensions API port

Select items (or a whole namespace) and mark them Core/Linux/Windows done, in progress, planned or not planned, assign an owner, and add notes.

Selecting: a click selects one item, Ctrl+click adds or removes one, Shift+click takes a range, and clicking the checkbox area toggles without clearing the rest. A namespace's checkbox selects everything in it. Ctrl+Z / Ctrl+Shift+Z undo and redo.

Where your work is stored:

  • Everything is saved in this browser automatically, so you can just start clicking. That copy is per-browser and per-origin, though — it is not the file the team shares.
  • Link file (Chromium only) binds a status.json on disk: every change is written to it straight away, and the link is restored the next time you open the page. Import & Link loads an existing file; Export & Link writes the browser's state into a new one (and warns before replacing an existing file).
  • Copy Path & Import / Copy Path & Export read and write that same status.json by hand — use these on Firefox and Safari, or to move state between browsers. Both copy this folder's path to the clipboard so you can paste it into the file dialog.
